# mc-packet-sniffer

A packet sniffing program for TCP client-server communication on a minecraft server (under certain conditions).

## Background

Over the years, I used to play a certain minecraft server, off and on (the same one for which I built the [door code brute forcer](https://github.com/jsmeya/door-code-brute-forcer)).
My idea for this packet analyzer was initially part of that brute forcer project. I wanted to see if I could read the traffic between my client and the server directly to uncover how the door code system works behind the scenes.
